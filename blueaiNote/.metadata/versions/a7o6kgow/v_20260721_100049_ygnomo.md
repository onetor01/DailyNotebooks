## Google Ads SDK 广告创建 API 报错分析

该日志记录了一次 **Demand Gen** 广告系列的完整创建流程，共经历 3 轮脚本执行，遇到了以下报错：

---

### 报错 1: CampaignCriterionService — `OWNED_AND_OPERATED` 地理位置定向不兼容

**原始输出：**

```
status = StatusCode.INVALID_ARGUMENT
details = "Request contains an invalid argument."

errors {
  error_code {
    request_error: UNKNOWN
  }
  message: "The error code is not in this version."
  trigger {
    string_value: "OWNED_AND_OPERATED"
  }
  location {
    field_path_elements {
      field_name: "operations" index: 0
    }
    field_path_elements { field_name: "create" }
    field_path_elements { field_name: "location" }
  }
}
request_id: "_ROubogWQZ489Y9CsQouVw"
```

**解析：**

- **API**: `CampaignCriterionService/MutateCampaignCriteria`
- **根因**: Demand Gen 广告系列**不支持**通过标准的 `geo_target_constant`（如 `geoTargetConstants/2276` = Germany）做地理位置定向。它使用 `OWNED_AND_OPERATED` 模式，location 定向需通过其他方式（如 campaign 层级的 geo targeting 设置或 UI）实现。
- **触发值**: `OWNED_AND_OPERATED`
- **SDK 版本问题**: `error_code: request_error: UNKNOWN` + `"The error code is not in this version."` 说明 API 返回了一个 SDK v24 尚未识别的错误码（服务端版本更新，但客户端 proto 未跟上）。
- **影响**: Campaign Budget 和 Campaign 创建成功，但 location criterion 创建失败。

### 报错 2: `'RepeatedComposite' object has no attribute 'add'`

**原始输出：**

```
AttributeError: 'RepeatedComposite' object has no attribute 'add'
File "resume_create_google_ads.py", line 142
    h = dg.headlines.add(); h.asset = rn
        ^^^^^^^^^^^^^^^^
```

**解析：**

- **API**: 本地 SDK 调用错误，未到达 Google 服务端
- **根因**: 使用了 `use_proto_plus=True` 模式，proto-plus 的 `RepeatedComposite` 不支持 `.add()` 方法（那是 raw protobuf 的接口）。应该使用 `.append()` 方法。
- **影响**: Assets 上传成功、Ad Group 创建成功、Audience Criterion 创建成功，但 AdGroupAd 创建时失败。

### 报错 3: `Unknown field for AdTextAsset: asset`

**原始输出：**

```
ValueError: Protocol message AdTextAsset has no "asset" field.
File "resume2_create_google_ads.py", line 72
    dg.headlines.append({"asset": rn})
```

**解析：**

- **API**: 本地 SDK 调用错误，未到达 Google 服务端
- **根因**: `DemandGenMultiAssetAdInfo.headlines` 的元素类型是 `AdTextAsset`，其字段是 `text`（文本内容）而非 `asset`（资源名）。而 `marketing_images` / `logo_images` 的元素类型是 `AdImageAsset`，其字段才是 `asset`（引用上传后的 asset resource_name）。
- **正确用法**:
  - `dg.headlines.append({"text": "标题文本"})` ← AdTextAsset 直接内联文本
  - `dg.marketing_images.append({"asset": "customers/xxx/assets/yyy"})` ← AdImageAsset 引用资源名
- **影响**: 修复后第三次执行全部成功。

### 报错 4: AgentTrace 业务层 — `user_action` 不合法

**原始输出：**

```json
{"message": "AgentTrace 业务错误 [code=40102]: user_action 不合法: CREATE_CAMPAIGN_BUDGET"}
{"message": "AgentTrace 业务错误 [code=40102]: user_action 不合法: CREATE_CAMPAIGN"}
{"message": "AgentTrace 业务错误 [code=40102]: user_action 不合法: CREATE_CAMPAIGN_CRITERION_LOCATION"}
```

**解析：**

- **来源**: 业务系统 `trace_log` 接口（非 Google Ads API）
- **根因**: 追踪日志的 `user_action` 枚举值未注册/未支持这些操作名，属于内部追踪系统配置问题，不影响 Google Ads API 实际调用。
