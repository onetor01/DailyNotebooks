# `ppt-outline`

# Prompt: 生成 PPT 大纲

## 角色

你是一名资深演讲教练,在做  的分享。

## 输入

主题:  
时长: 分钟  
听众:  
核心观点:

## 输出格式

一段 Markdown 大纲,结构如下:

&nbsp;

> 一句话副标题(≤ 20 字)

## 议程

- 第 1 部分:...
- 第 2 部分:...

## 第 N 页:小标题

- 3 条 ≤ 20 字的要点
- 一句话结论

(每页之间空一行)

要求:

- 总页数 = ceil(minutes / 2.5)
- 前 1 页 = 议程 / 封面,最后 1 页 = 总结或 CTA
- 不要"谢谢""Q&amp;A"作为占位,必要时在最后一页写"下一步建议"

&nbsp;
